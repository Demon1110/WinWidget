## WinWidget 代码审查与三轮修复（未 push，仅本地提交）

项目：Rust 重写的 Windows 桌面小组件工具（tao/wry + WebView2，38 个内置组件）。

做了三轮修复，每轮验证 fmt/clippy -D warnings/41 个测试通过后提交：

1. `9dd5292` CI 门禁：cargo fmt 全量格式化 + 修 4 个 clippy 错误（clipboard.rs redundant closure、paths.rs single_match/vec_init_then_push、schedule.rs manual_is_multiple_of）。此前项目连自己的 CI 门禁都过不了。
2. `2ca64b1` 高危 bug：
   - typeText 中文/emoji 截断：keybd_event 的 scan 是 BYTE，换 SendInput + KEYBDINPUT.wScan（手写 INPUT/KEYBDINPUT repr(C) 绑定）
   - dib_to_png 越界读：按 GlobalSize 校验 DIB 头和像素区，防其他进程放入畸形数据导致 UB
   - win.create 立即返回 destroyed:true：pending_customs 里的窗口现在报 destroyed:false/loaded:false
   - db.rs Store：落盘改 tmp+rename 原子写；load 解析失败备份 .broken-* 文件而非静默当空表（防下一次 put 清空数据）
3. `1b87fea` 中等修复：
   - packages::create 改用 hello-widget 模板（按 locale 选 zh-CN/en），不再强制开全局 developer_mode
   - install_staged 回收旧目录失败时报错中止，不再新旧文件混装
   - app.restart 删掉 exit(0)，走正常 quit 流程（unload 宽限/保存/托盘清理）
   - 启动清扫 .install 暂存残留；删除死代码 App::scale、fullscreen_app_running、place 的 inner 参数
   - README 删掉已修复的已知限制条目
