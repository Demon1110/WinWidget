# 组件承载面规范（surface）

一个组件包只写一份代码，但可以声明它适合在哪种**承载面**上出现：

- `desktop`：桌面挂件。常驻、贴桌面、随开机恢复。
- `window`：窗口工具。用时打开、用完关闭，有任务栏项、可聚焦、可缩放。

两者不是两个组件包，也不是两套目录。差别在生命周期、权限和资源预算，页面代码共用。

## 一、判据

先问四个问题，任意一条命中 `window` 就按窗口工具落：

1. 需要键盘输入、多步流程、大画布、拖拽或长列表吗？
2. 是不是一次任务：打开 → 输入 → 处理 → 拿走结果 → 关闭？
3. 是否需要"用时确认"的敏感权限（录屏、WiFi 明文、剪贴板读取）？
4. 常驻会不会产生持续开销（扫描目录、跑编码、轮询句柄）？

反过来，命中以下任一条就按桌面挂件：

- 用户需要一眼看到（时间、状态、端口、HDR、电量）。
- 提供氛围或轻交互（特效、按键显示、小游戏）。
- 不需要输入，点击最多触发一次复制或切换。
- 常驻开销可以稳定压在限帧预算内（≤ 4 fps 的绘制或 1 次/秒的读值）。

两面都合适的组件（例如取色、迷你端口面板）可以同时声明，由用户决定钉到桌面还是开成窗口。

## 二、manifest 字段

```json
{
  "surfaces": ["desktop", "window"],
  "defaultSurface": "desktop",
  "window": {
    "width": 760,
    "height": 560,
    "minWidth": 520,
    "minHeight": 360,
    "maxWidth": 2400,
    "maxHeight": 2000,
    "singleInstance": true
  }
}
```

规则：

- `surfaces` 省略 = `["desktop"]`，旧包不需要改。
- 取值只能是 `desktop` / `window`，不允许重复。
- `defaultSurface` 必须在 `surfaces` 里；省略时取数组第一项。
- 只声明 `window` 时，`window` 对象必填，且 `width/height` 必须 ≥ `minWidth/minHeight`。
- `window.singleInstance` 默认 `true`：同一组件再次打开时聚焦已有窗口，不叠新窗口。
- 桌面挂件仍用顶层 `size`；窗口工具用 `window` 里的尺寸，`size` 只作为旧宿主的兜底。

## 三、两类运行时差异

桌面挂件：

- 进 `instances`，随开机恢复；记位置、尺寸、层级、锁定、穿透。
- 参与虚拟桌面隔离：不属于当前桌面的卡片隐藏而不是销毁。
- 无任务栏项、不抢焦点、不进 Alt+Tab。
- 主题、圆角、透明、内描边、低资源限帧全部生效。
- 关闭（卸载/隐藏）即销毁窗口，重开按配置恢复。

窗口工具：

- 也有一条实例记录（用于设置、`storage`、权限与上次几何），但**启动时不建窗**，只在"打开"时创建。
- 有系统标题栏、任务栏项、最小化/最大化、可缩放；不进虚拟桌面隔离，跟随 Windows 自身行为。
- 关闭窗口只销毁窗口，保留实例记录与 `storage`；再次打开恢复上次位置和尺寸。
- 不应用卡片外观（圆角、投影、点击穿透、锁定、置顶层）；使用主题的实色背景。
- 失焦不自动关闭、不自动隐藏；只有用户关闭或宿主退出才结束。
- 窗口内页面自动获得键盘焦点；`Esc` 关闭由页面自行决定，宿主不强制。

页面据此自适应：

- `widget.surface` 返回 `"desktop"` 或 `"window"`。
- 宿主在 `<html>` 上写 `data-surface`，SDK 同时提供 `--w-surface` 变量（值同上）。
- 窗口面下 `body` 使用 `--w-bg-solid`，圆角与投影归零；页面不要假设自己只有 240×120。

## 四、权限与资源

- 桌面挂件只应申请只读、低风险的常驻权限；写操作、批量文件、录屏这类能力默认不给挂件。
- 窗口工具可以申请敏感权限，但第一次使用仍走控制中心的授权面板；将来引入"会话授权"时，授权随窗口关闭失效。
- 桌面挂件的绘制预算：静止时 ≤ 1 fps，动效 ≤ 30 fps，禁止常驻轮询高于 1 Hz 的文件/网络操作。
- 窗口工具只在可见且聚焦时全速运行；失焦后可降到 4 fps，最小化后停止定时器。
- 单实例窗口工具不得在隐藏状态下继续跑长任务；长任务要么显式后台化并在托盘提示，要么拒绝启动。

## 五、入口与文案

- 控制中心与 Hub 列表统一叫法：桌面面叫「桌面挂件」，窗口面叫「窗口工具」。
- 只声明 `window` 的组件，安装动作是「打开」，不出现「放到桌面」。
- 同时声明两面的组件，主按钮按 `defaultSurface` 决定，次按钮提供另一面（「放到桌面」/「打开窗口」）。
- 窗口工具的卡片说明里要写清"用完关闭"，避免用户以为它会常驻。

## 六、试点与验收

第一批试点选两个差异最大的窗口工具：

1. `emoji-search`：验证"热键/入口打开 → 键盘输入 → 复制 → 关闭"的最短路径，检查焦点、Esc、单实例。
2. `image-batch`：验证大画布、目录读取、长任务进度、关闭即中断，检查不残留后台线程与临时文件。

验收项：

- 冷启动打开 ≤ 400 ms，二次打开 ≤ 200 ms。
- 关闭后进程内无该组件的窗口与定时器；`config.json` 里实例记录仍在，`storage` 数据不丢。
- 重开恢复上次位置与尺寸；单实例重复打开只聚焦，不叠窗。
- 桌面挂件行为零回归：位置、层级、穿透、虚拟桌面隔离、低资源模式均不变。
