## 十分鐘寫第一個組件

我們來做一個「每日一句」：每天顯示一句話，按一下換下一句，句子可以在控制中心改。

### 1. 建立組件（1 分鐘）

1. 左鍵點托盤圖標，打開控制中心。
2. 到控制中心「添加組件」頁，按右上角的 **新建組件…**（視窗窄時只顯示「＋」圖標）。也可以右鍵系統匣圖標 →「添加組件」→「新建組件…」。
3. 名稱輸入 `每日一句`，按 **建立**。

WinWidget 會：

- 在組件目錄建立一個資料夾（例如 `%AppData%\WinWidget\widgets\my-widget`），裏面是一個能用的模板；
- 把它放到桌面；
- 打開 **開發者模式**：之後改了資料夾裏的檔案，一存檔，桌面上的組件就會自動重新載入；
- 用檔案總管打開這個資料夾。

用你習慣的編輯器打開這個資料夾。推薦 [VS Code](https://code.visualstudio.com/)：資料夾裏的 `widget.d.ts` 會讓它在你打 `widget.` 時列出所有可用的功能和說明。

### 2. 加一個設定項（1 分鐘）

打開 `widget.json`，把 `settings` 整段換成：

```json
"settings": [
  { "key": "quotes", "type": "textarea", "label": "句子（一行一句）",
    "default": "慢慢來，比較快。\n今天也要好好吃飯。\n先完成，再完美。" }
]
```

存檔。打開控制中心 →「我的組件」→ 選「每日一句」→「內容」，會看到一個多行文字框，裏面是這三句話。這個表單是 WinWidget 照 `settings` 自動生成的。

### 3. 寫畫面（3 分鐘）

把 `index.html` 換成：

```html
<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="w-label" id="day"></div>
  <p class="quote" id="quote"></p>
  <button class="w-btn" id="next">換一句</button>
  <script src="main.js"></script>
</body>
</html>
```

把 `style.css` 換成：

```css
body {
  display: flex;
  flex-direction: column;
  gap: 8px;
}

.quote {
  flex: 1;
  margin: 0;
  font-size: 1.3rem;
  line-height: 1.5;
}

#next {
  align-self: flex-end;
}
```

`<body>` 就是那張卡片。`w-label`、`w-btn` 是 WinWidget 自帶的樣式，背景、圓角、字體和顏色由主題提供，你不用寫。

### 4. 寫邏輯（3 分鐘）

把 `main.js` 換成：

```js
const $ = (id) => document.getElementById(id);
let quotes = [];
let index = 0;

function show() {
  const quote = quotes.length ? quotes[index % quotes.length] : "到控制中心加幾句話吧";
  $("quote").textContent = quote;
  $("day").textContent = new Date().toLocaleDateString(widget.locale, {
    month: "long", day: "numeric", weekday: "long",
  });
}

// 讀設定：一行一句
function load(settings) {
  quotes = settings.quotes.split("\n").map((s) => s.trim()).filter(Boolean);
  show();
}

// 每天自動換一句；按過「換一句」的話，記住今天換到哪一句
const today = new Date().toDateString();
widget.storage.get("pick").then((pick) => {
  const dayNumber = Math.floor(Date.now() / 86400000);
  index = pick && pick.day === today ? pick.index : dayNumber;
  load(widget.settings.get());
});

// 用戶在控制中心改了句子，馬上更新
widget.settings.onChange(load);

$("next").addEventListener("click", () => {
  index++;
  widget.storage.set("pick", { day: today, index });
  show();
});
```

存檔，桌面上的組件馬上變成新的樣子。試試：

- 按「換一句」；
- 在控制中心改句子，桌面上即時更新；
- 到「主題」換一套主題，組件的字體和顏色會跟着變；
- 重新啟動 WinWidget，今天換到的那一句還在（`widget.storage` 會一直保存）。

### 5. 出錯了怎麼辦（1 分鐘）

開發者模式下，腳本出錯時卡片底部會出現一條紅色提示，寫着錯誤和位置（例如 `main.js:12`）。點一下它就會打開開發者工具；也可以在組件上按 **F12**。改好存檔，提示就會消失。

### 6. 分享出去（1 分鐘）

控制中心 →「添加組件」→ 你的組件卡片 →「匯出 .fwz」。別人雙擊這個 `.fwz` 檔案就能安裝（也可以拖到控制中心視窗上）。

想讓所有人都能在控制中心的「線上」裏找到它，可以投稿到[組件市場](https://hmgvibe.github.io/fullwidget-market/)：把組件資料夾放進 GitHub 上 [fullwidget-market](https://github.com/hmgvibe/fullwidget-market) 儲存庫的 `widgets/你的帳號.組件名/`，開一個 pull request。自動檢查通過、維護者看過後就會上架，詳細步驟見那裏的 CONTRIBUTING.md。

## 資料夾裏有什麼

| 檔案 | 用途 |
|---|---|
| `widget.json` | 說明檔：名稱、尺寸、權限、設定項。**必須有。** |
| `index.html` | 組件的頁面（可以在 `widget.json` 的 `entry` 改成別的檔名）。 |
| `style.css`、`main.js` | 樣式和邏輯。檔名隨意，在 HTML 裏用相對路徑引用即可。 |
| `icon.svg` | 在組件庫、托盤選單和控制中心顯示的圖標（建議 24×24 的 SVG）。 |
| `widget.d.ts`、`jsconfig.json` | 只給編輯器用，讓它提示 `widget.` 的寫法。 |

組件目錄：`%AppData%\WinWidget\widgets\`。在控制中心「設定」→「組件目錄」可以直接打開。把一個組件資料夾放進去，它就會出現在「添加組件」裏（開發者模式下自動出現，否則按「重新掃描」）。

檔案請存成 **UTF-8**。

## widget.json

可以寫 `//` 註解，最後一項後面多一個逗號也沒關係。

```json
{
  "id": "me.daily-quote",
  "name": { "zh-TW": "每日一句", "zh-CN": "每日一句", "en": "Daily Quote" },
  "description": "每天一句話",
  "version": "1.0.0",
  "author": "你的名字",
  "entry": "index.html",
  "icon": "icon.svg",
  "category": "info",
  "size": {
    "width": 280, "height": 160,
    "minWidth": 200, "minHeight": 120, "maxWidth": 600, "maxHeight": 400,
    "resizable": true
  },
  "layer": "desktop",
  "permissions": [],
  "settings": []
}
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `id` | 是 | 唯一識別碼。小寫英文、數字和 `. _ -`，2–64 個字元，例如 `me.daily-quote`。之後不要改：保存的資料和更新都靠它。`winwidget.` 開頭的留給內建組件。 |
| `name` | 建議 | 顯示的名稱。可以是文字，也可以按語言給：`{ "zh-TW": "…", "en": "…" }`。 |
| `description` | | 一句話介紹，顯示在組件庫。同樣可以按語言給。 |
| `version` | 建議 | 版本號，例如 `1.2.0`。安裝 `.fwz` 時用它判斷是更新、重新安裝還是舊版本。 |
| `author` | | 作者。 |
| `entry` | | 頁面檔，預設 `index.html`。 |
| `icon` | | 圖標檔。沒有的話顯示名稱的第一個字。 |
| `category` | | 在組件庫裏放在哪一類：`time`（時間）、`weather`（天氣）、`system`（系統）、`productivity`（效率）、`info`（資訊）、`media`（媒體與裝飾）。不寫或寫別的，放在「其他」。 |
| `preview` | | 組件庫卡片上的預覽圖，例如 `"preview.png"`。可以按主題和語言各放一張：`"preview/{theme}.{lang}.webp"`，`{theme}` 換成主題 id（`instrument`、`type`、`paper`），`{lang}` 換成 `zh-TW`、`zh-CN` 或 `en`；缺的那張會用同主題的其他語言，或其他主題代替。圖片建議用透明背景的 PNG 或 WebP，寬 300 像素左右。沒有的話卡片顯示圖標。 |
| `size` | | 卡片尺寸（不含陰影），單位是像素。`width`/`height` 是第一次放上桌面的大小；`min*`/`max*` 限制用戶拖動縮放的範圍；`resizable: false` 不讓縮放；`grow`（0–1）決定用戶把卡片拉得比預設大時，內容要不要跟着放大，見[放大時內容跟着變大](#放大時內容跟着變大)。 |
| `layer` | | 第一次放上桌面時的層級：`desktop`（預設，在所有視窗下面，Win+D 也看得到）、`normal`、`top`（置頂）。用戶之後可以改。 |
| `permissions` | | 要用到的權限，見[權限](#權限)。 |
| `settings` | | 設定項。控制中心會照這裏自動生成表單。 |

### settings：設定項

每一項：

```json
{
  "key": "city",
  "type": "text",
  "label": "城市",
  "description": "留空就自動定位",
  "default": ""
}
```

| 欄位 | 說明 |
|---|---|
| `key` | 程式裏用的名字：`widget.settings.get("city")`。 |
| `type` | 見下表。 |
| `label` | 表單上的名稱。可以按語言給。 |
| `description` | 名稱下面的一行小字說明。 |
| `default` | 預設值。任何類型都可以按語言給，例如 `{ "zh-TW": "google", "zh-CN": "baidu", "en": "google" }`。 |
| `placeholder` | 輸入框裏的提示文字。 |
| `min` `max` `step` | `number` 和 `slider` 用。 |
| `options` | `select` 用：`[{ "value": "c", "label": "攝氏" }, { "value": "f", "label": "華氏" }]`。 |

| type | 表單 | 值 |
|---|---|---|
| `toggle` | 開關 | `true` / `false` |
| `text` | 單行文字 | 字串 |
| `textarea` | 多行文字 | 字串（換行是 `\n`） |
| `number` | 數字框 | 數字 |
| `slider` | 滑桿 | 數字 |
| `select` | 下拉選單（三個以內的短選項會顯示成分段按鈕） | 選項的 `value` |
| `color` | 顏色 | `"#rrggbb"` |
| `font` | 字體（可從系統字體中選） | 字體名稱；用戶清空時是 `null`（通常就用主題的字體） |
| `date` | 日期 | `"2026-12-31"` |
| `folder` | 資料夾（顯示路徑和「選擇…」按鈕） | 完整路徑；預設值可以寫環境變數，例如 `"%USERPROFILE%\\Pictures"`。見 [`widget.files`](#讀取用戶選的資料夾widgetfiles) |

## JavaScript API

WinWidget 會在你的腳本執行前準備好全局的 `widget`，不用 import。完整的型別和說明在 `widget.d.ts`。

需要等待的功能（讀寫資料、連網等）都回傳 Promise，可以用 `await`。

### 基本資料

```js
widget.id          // "me.daily-quote"
widget.instanceId  // 桌面上這一個的識別碼（同一個組件可以放幾個）
widget.locale      // 用戶的語言，例如 "zh-TW"，格式化日期和數字用
widget.theme       // 目前的主題："instrument"、"type"、"paper"
widget.developer   // 是否在開發者模式
widget.permissions // 現在能用的權限

// 按用戶的語言挑文字
widget.t({ "zh-TW": "早安", "zh-CN": "早安", en: "Good morning" })
```

### 設定：`widget.settings`

```js
// 讀設定：同步的，不用 await
const all = widget.settings.get();         // { quotes: "…", … }
const one = widget.settings.get("quotes");

// 用戶在控制中心改了設定
widget.settings.onChange((all) => { /* … */ });

// 程式也可以改，控制中心會同步顯示
await widget.settings.set("quotes", "…");
```

### 保存資料：`widget.storage`

保存的東西重開電腦也在；用戶移除這個組件時一起刪除。桌面上每一個組件各有自己的一份。上限每個 2 MB。

```js
// 可以存任何 JSON 資料
await widget.storage.set("todo", [{ text: "買牛奶", done: false }]);

// 沒存過的是 null
const todo = (await widget.storage.get("todo")) || [];

await widget.storage.remove("todo");
const keys = await widget.storage.keys();
```

### 系統資訊：`widget.system`（需要 `system` 權限）

```js
const stop = widget.system.subscribe(["cpu", "memory"], (d) => {
  cpu.textContent = Math.round(d.cpu.usage) + "%";
  mem.textContent = Math.round(d.memory.usage) + "%";
}, { interval: 2000 });  // 每 2 秒一次，預設 1 秒；第一筆會馬上到

stop(); // 不需要時停止
```

| 主題 | 內容 |
|---|---|
| `cpu` | `usage`（%）、`cores` |
| `memory` | `usage`（%）、`total`、`used`、`available`（位元組） |
| `network` | `down`、`up`（每秒位元組）、`totalDown`、`totalUp` |
| `disk` | 每個磁碟一項（含隨身碟）：`name`（"C:"）、`label`、`type`（`fixed` / `removable`）、`total`、`free`、`usage`（%） |
| `battery` | `present`、`percent`、`charging`、`pluggedIn`、`secondsLeft`、`saver`（省電模式） |

多個組件訂閱同一個數據時，WinWidget 只取樣一次，不會多耗資源。

不常變的資料用一次性的呼叫：

```js
const pc = await widget.system.info();
// pc.os.name "Windows 11 Pro"、pc.os.version "25H2"、pc.cpu.name、pc.memory.installed（位元組）、
// pc.gpus（顯示卡名稱）、pc.computer（電腦名稱）、pc.uptime（已開機的毫秒數）

const net = await widget.system.adapters();
// net.online；net.adapters[0] 是連上網路的那個：name "Wi-Fi"、type "wifi"、ipv4、gateways、dns

const r = await widget.system.ping("1.1.1.1");   // { ok, ms, status }；每個組件每秒最多一次
```

### 音量：`widget.audio`（需要 `audio` 權限）

```js
const stop = widget.audio.onChange((a) => {
  // a.volume 0–100、a.muted、a.device（"喇叭 (Realtek Audio)"）
  // 按鍵盤的音量鍵、工作列調音量、換成耳機時都會馬上通知
});
await widget.audio.set({ volume: 40 });
await widget.audio.set({ muted: true });
```

### 正在播放：`widget.media`（需要 `media` 權限）

讀取 Windows 媒體控制裏正在播放的內容（Spotify、瀏覽器、媒體播放器……，和音量面板上看到的一樣），並控制它：

```js
widget.media.onChange((m) => {
  if (!m.available) return;          // 沒有程式在播放
  // m.title、m.artist、m.album、m.app.name（"Spotify"）、m.app.icon
  // m.playing、m.position、m.duration（毫秒）、m.cover（封面圖片的網址，可直接放進 <img>）
  // m.can.next、m.can.previous、m.can.seek：那個程式現在接受哪些按鈕
});
const now = widget.media.position(m);   // 現在播到哪裏（播放中會自己往前走）
await widget.media.toggle();            // 播放 / 暫停；也有 play()、pause()、next()、previous()
await widget.media.seek(60000);         // 跳到 1:00
// 目前這首歌的時間軸歌詞，在網易雲音樂、QQ 音樂、酷狗上查找
const { title, lyrics } = await widget.media.lyrics();
if (lyrics.found) lyrics.lines;         // [{ t: 毫秒, text, tr?: 翻譯 }]，按時間排好
```

Windows 有變化時會馬上通知（換歌、暫停、換了一個程式在播放），不用自己輪詢。

### 讀取用戶選的資料夾：`widget.files`

在設定項裏放一個 `folder` 類型的設定，用戶選了資料夾，組件就能讀取裏面的圖片。**選資料夾本身就是允許**，不用在 `permissions` 聲明：

```json
{ "key": "folder", "type": "folder", "label": "照片資料夾", "default": "%USERPROFILE%\\Pictures" }
```

```js
const { files } = await widget.files.list("folder", { recursive: true });
// files: [{ path: "2025/海邊.jpg", name: "海邊", size, modified, url }]
img.src = widget.files.url(files[0], { width: 800 });   // Windows 做的縮小版，大照片也很快、很省記憶體
const { taken } = await widget.files.info("folder", files[0]);  // 拍攝時間（相機記錄的），沒有時是 null
await widget.files.pick("folder");      // 在組件裏直接打開選資料夾的視窗，選好後存進設定
```

- 只能讀那個資料夾（和裏面的子資料夾）裏的圖片：jpg、png、gif、webp、bmp、avif、heic、tif，最多 5000 張。
- 別人寫的組件，`default` 裏寫的資料夾不算數，要等用戶自己選過才能讀。內建組件和自己寫的組件可以用預設值。
- 資料夾的設定值裏可以寫環境變數，例如 `%USERPROFILE%`。

### 連網：`widget.fetch`（需要 `network:` 權限）

和瀏覽器的 `fetch` 很像，但由 WinWidget 代為發送，所以不受 CORS 限制：

```js
const r = await widget.fetch(
  "https://api.open-meteo.com/v1/forecast?latitude=25&longitude=121&current=temperature_2m"
);
if (r.ok) {
  const data = await r.json();
}

await widget.fetch("https://example.com/api", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: { hello: "world" },   // 物件會自動轉成 JSON
});
```

回應有 `ok`、`status`、`statusText`、`url`、`headers`、`body`（文字）、`text()`、`json()`。圖片等二進位內容用 `{ as: "base64" }`，`body` 就是 base64 文字。每次最多 8 MB，會自動跟隨轉址（每一跳都要在權限內）。

### 打開網址：`widget.shell.open`（需要 `shell.open` 權限）

```js
// 用預設瀏覽器打開；也接受 mailto:
widget.shell.open("https://example.com");
```

組件頁面本身不能跳轉到別的網址，也不能開新視窗；要打開網頁請用這個。

### 打開程式和檔案：`widget.shell.launch`（需要 `shell.launch` 權限）

```js
await widget.shell.launch("C:\\Windows\\notepad.exe");    // 程式、捷徑、資料夾、文件都可以；不能帶參數

const path = await widget.shell.pick({ type: "file", filter: "programs" }); // 讓用戶選；取消時是 null
const info = await widget.shell.info(path);  // { name: "記事本", kind: "app", icon: "data:image/png;…" }

// 檔案拖到組件上時取得完整路徑
document.addEventListener("dragover", (e) => e.preventDefault());
document.addEventListener("drop", async (e) => {
  e.preventDefault();
  const paths = await widget.shell.paths(e.dataTransfer.files);
});
```

`pick` 的 `type` 可以是 `file` 或 `folder`，`filter` 可以是 `programs`、`images` 或 `all`。

### 簡繁轉換：`widget.convertChinese`

```js
await widget.convertChinese("北极熊和幼崽", "traditional");  // "北極熊和幼崽"
```

用 Windows 內建的字表逐字轉換，適合短句（例如網上取得的簡體標題），不處理「軟件 / 軟體」這類用詞差異。不需要權限。

### 通知：`widget.notify`（需要 `notify` 權限）

```js
// 馬上彈出一則 Windows 通知（標題預設是組件名稱）
widget.notify("下載完成");

// 預約在某個時間；同一個 tag 的新預約會取代舊的
widget.notify({ title: "番茄鐘", body: "休息一下", at: Date.now() + 25 * 60 * 1000, tag: "end" });

widget.notify.cancel("end"); // 取消這個預約；不給 tag 就取消這個組件的全部預約
```

預約由 WinWidget 計時，所以就算組件因為全螢幕或「隱藏全部組件」暫停了，通知也會準時出現。最多預約 7 天以內、每個組件 20 則；電腦睡眠醒來時，遲了超過 15 分鐘的預約不再顯示。

### 視窗：`widget.window`

```js
const { width, height } = await widget.window.getSize();
await widget.window.setSize(320, 200);   // 會被限制在 size 的 min/max 之內
```

### 外觀和事件

```js
// 目前的主題和外觀值
widget.appearance.get();

// 換主題或改外觀時（CSS 變數已經更新好了）
widget.appearance.onChange((a) => {});

// 鎖定、層級、滑鼠穿透改變時：{ locked, layer, clickThrough }
widget.on("state", (s) => {});

// 被快捷鍵叫出來時（目前是便籤和待辦清單的快捷鍵，叫出 winwidget.notes、winwidget.todo）：把游標放進主要的輸入框
widget.on("summon", () => {});

// 寫進 WinWidget 的日誌
widget.log("訊息", { any: "data" });
```

## 生命週期：ready → show → hide → unload

一張卡片從被載入到被移除，外殼會按固定順序發事件。全部用 `widget.on(名稱, 回呼)` 訂閱，回傳值是退訂函式。

| 事件 | 什麼時候來 | 內容 |
|---|---|---|
| `ready` | 頁面起來了（DOMContentLoaded 之後再過一個工作，所以你寫在 DOMContentLoaded 裡的訂閱一定聽得到） | `{ visible }` |
| `show` | 卡片出現在螢幕上。**開機那次也算一次**，帶 `initial: true` | `{ from, visible: true, initial }` |
| `hide` | 卡片離開螢幕：隱藏全部、托盤單張隱藏、全螢幕讓位、`window.hide()` | `{ from, visible: false, initial: false }` |
| `resize` | 卡片尺寸變了（拖邊、拖角、控制中心改大小）。連續變化會**去抖 80ms**，只回報停下來的那一個 | `{ width, height }`，CSS 像素 |
| `unload` | 卡片要被移除、或整個程式要結束 | `{ kill: true }` |

`from` 說明這次顯示/隱藏是誰造成的：

| `from` | 誰 |
|---|---|
| `startup` | 開機跟著外殼一起顯示 |
| `tray` | 托盤選單（顯示/隱藏全部、單張顯示/隱藏） |
| `control` | 控制中心（「定位」、顯示全部開關） |
| `hotkey` | 全域快捷鍵叫出來 |
| `fullscreen` | 有別的全螢幕程式，這張卡片讓開或回來 |
| `api` | 卡片自己呼叫 `widget.window.show()` / `hide()` |

### 順序保證

1. `ready` 一定比第一個 `show` 早。所以「啟動時要做一次」的初始化寫在 `ready` 裡，不會被 `show` 打亂。
2. 已經在螢幕上的卡片（開機預設）會在 `ready` 後立刻收到 `show{ initial: true }`；啟動時被隱藏的（例如開了「隱藏全部」）不會收到，等真的顯示才有。
3. `show` / `hide` 是成對的，而且同一個狀態不會重複發：`hide` 之後再 `hide` 沒有第二次；`show` 之後再 `show` 也沒有。用 `widget.visible` 隨時查目前狀態。
4. `hide` 會在卡片仍活著的時候到，`unload` 是「這次真的要走了」。只做一次的事（存檔、關定時器）放 `unload`，暫停動畫放 `hide`。

```js
// 邊跑邊省電：看不見就停，回來再算一次
let timer = 0;
function start() {
  if (timer || !widget.visible) return;
  timer = setInterval(tick, 1000);
  tick();
}
function stop() {
  clearInterval(timer);
  timer = 0;
}

widget.on("ready", () => start());
widget.on("show", ({ from, initial }) => {
  widget.log("shown", from, initial);   // from 見上表
  start();
});
widget.on("hide", () => stop());
widget.on("unload", ({ kill }) => {
  stop();
  if (kill) widget.storage.set("lastSeen", Date.now());
});

// 尺寸變了再排版（不用聽 window 的 resize，那是整窗，帶 DPI 換算）
widget.on("resize", ({ width, height }) => {
  document.body.dataset.compact = width < 260 ? "1" : "";
});
```

`widget.visible` 是隨時可讀的目前狀態，SDK 會跟著 `show` / `hide` 更新。卡片刻意不去搶鍵盤焦點，所以沒有 focus / blur 事件；要用鍵盤輸入的組件，自己在卡片裡放輸入框，使用者點它才會拿到鍵盤。

### 和 uTools 那七個事件的對照

uTools 的事件是「外掛程式 vs 主視窗」的模型；WinWidget 的卡片本身就是一個獨立視窗，所以只能對到形狀相同的那幾個：

| uTools | WinWidget | 差在哪 |
|---|---|---|
| `onPluginReady(cb)` | `widget.on("ready", cb)` | 一樣只在載入後一次。uTools 會等 `cb` 的 Promise；這裡不會等，要「等完再進」用 `utools.onPluginReady` |
| `onPluginEnter(cb)` | `widget.on("show", cb)` | 參數形狀見下；每次顯示都觸發，不只是第一次 |
| `onPluginOut(cb)` | `widget.on("hide", cb)` + `widget.on("unload", cb)` | `hide` 對應 `isKill: false`，`unload` 對應 `isKill: true` |
| `onPluginDetach(cb)` | 無 | 卡片本來就是獨立視窗，沒有「分離」這一步；`utools.onPluginDetach` 會登記但不觸發 |
| `onScheduleTrigger(cb)` | 無 | 沒有排程器。要定時做事就在頁面裡用 `setInterval`，卡片被隱藏時記得停 |
| `onMainPush(cb, onSelect?)` | 無 | 沒有 uTools 那種搜尋框可以推結果 |
| `onDbPull(cb)` | 無 | 沒有跨裝置同步；資料留在本機 `widget.storage` |

`utools.onPluginEnter` 的參數按 uTools 的 `PluginEnterAction` 給：`{ code, type: "text", payload: "", from }`，`from` 是 uTools 的詞（`main` / `panel` / `hotkey` / `redirect`），由上表的 `from` 映射過來：`startup`、`fullscreen` → `main`，`tray` → `panel`，`hotkey` → `hotkey`，`control`、`api` → `redirect`。`option` 只有在「從推送結果進來」時才有，這裡不會有。

## 外觀：跟着主題走

WinWidget 有幾套主題，用戶也能在控制中心調整背景、文字顏色、強調色、字體、字號、圓角、內距和透明度。只要你的組件用下面這些變數和樣式，這一切都會自動生效。

### 版面

- `<body>` 就是卡片：背景、圓角、邊框、內距都已經設好。內容直接放進 `<body>`。
- `<html>` 是透明的視窗，四周留了給陰影的空白，不要給它加背景。
- 字號用 `rem`：用戶調「字號」時，`1rem` 會跟着變（預設 14px）。
- 卡片可能被縮放。用 flex/grid 排版；要按大小調整，可以在 `body` 上設 `container-type: size`，再用 `@container (max-height: 100px) { … }`。注意 `@container` 只能改 `body` 裏面的元素，改不了 `body` 本身。

### 放大時內容跟着變大

在 `widget.json` 的 `size` 加上 `"grow": 1`，用戶把卡片拉得比預設大時，整張卡片的內容會一起放大，字、圖標、間距都按比例變大，不會只是多出空白：

```json
"size": { "width": 260, "height": 150, "minWidth": 180, "minHeight": 110, "grow": 1 }
```

- 放大的倍數是「寬放大幾倍」和「高放大幾倍」中較小的那個，最多 3 倍。例如拉到兩倍寬、1.3 倍高，內容放大 1.3 倍，多出來的寬度交給你的排版。
- 比預設小時不會縮小，小尺寸要靠你自己的排版（上面的 `@container`）。
- `grow` 可以是 0 到 1 之間：清單類的組件寫 `0.5`，拉大時字變大一點，同時多顯示幾項。
- 不寫或寫 `0`：和以前一樣，只是多出空間。
- 卡片的圓角、邊框和陰影不會跟着放大。目前的倍數在 CSS 變數 `--w-size-scale`。

### CSS 變數

| 變數 | 用途 |
|---|---|
| `--w-fg` | 主要文字顏色 |
| `--w-fg-muted` | 次要文字（標籤、說明） |
| `--w-fg-faint` | 很淡的文字、分隔 |
| `--w-accent` | 強調色：進度、選中、重點數字 |
| `--w-on-accent` | 放在強調色上面的文字 |
| `--w-warn` `--w-danger` | 警告、危險 |
| `--w-bg` | 卡片背景（已用在 body 上） |
| `--w-bg-solid` | 卡片的顏色，但不透明：用在要擋住後面內容的地方，例如彈出的清單 |
| `--w-border` `--w-rule` | 邊框、分隔線 |
| `--w-track` | 進度條的底 |
| `--w-control-bg` `--w-hover` | 輸入框底色、滑過時的底色 |
| `--w-font` | 內文字體 |
| `--w-font-num` | 數字的字體 |
| `--w-font-display` | 組件裏那個最大的數字（時間、溫度）的字體 |
| `--w-font-title` | 標題字體 |
| `--w-radius` `--w-padding` | 卡片圓角、內距 |

### 現成的樣式

| class | 用途 |
|---|---|
| `w-label` | 小號、次要顏色的標籤文字 |
| `w-title` | 標題 |
| `w-num` | 數字（等寬、主題的數字字體） |
| `w-display` | 最大的那個數字 |
| `w-rule` | 分隔線（用在 `<hr>` 或 `<div>`） |
| `w-bar` | 進度條：`<div class="w-bar"><i style="width:40%"></i></div>`；加 `is-warn` 變成警告色 |
| `w-input` | 輸入框 |
| `w-btn` | 按鈕；加 `is-primary` 變成強調色按鈕 |
| `w-check` | 圓形勾選框：`<button class="w-check" aria-pressed="true">` |

### 按主題微調

`<html>` 上有這些屬性，可以寫專門的樣式：

```css
/* 某一套主題 */
html[data-theme="paper"] .quote { font-style: italic; }

/* 用戶選了毛玻璃卡片 */
html[data-style="frosted"] .quote { letter-spacing: 0.02em; }

/* 組件被鎖定時 */
html[data-locked="true"] #next { display: none; }
```

用戶也可以在控制中心「外觀 → 自訂 CSS」給單一組件加樣式，它會排在你的 CSS 之後。

### 省電：每秒更新的東西不要加動畫

組件整天開着，每一幀畫面都要算。每秒更新一次的數字或進度條，如果加了 0.5 秒的 `transition`，畫面就幾乎一直在動，一個組件可以吃掉 20% 的處理器核心；不加的話只要 1%。

- 每秒或更頻繁更新的元素，不要 `transition` 和 `animation`。`w-bar` 預設有 0.5 秒的寬度動畫，每秒更新時寫 `.w-bar > i { transition: none; }`。
- 不要 `animation: … infinite`；要閃爍提示，給一個次數（例如 `8`）。
- 指針、轉盤這類要轉的東西，放在獨立的元素上用 CSS `transform` 轉，不要每秒重畫整個 SVG。
- 每分鐘才變的東西，就每分鐘才更新（`setTimeout` 對準下一分鐘）。

## 拖動、選單和點擊

WinWidget 已經幫你處理好：

- **拖動**：在卡片任何地方按住拖動，就能移動組件。按鈕、連結、輸入框不會觸發拖動；其他元素不想被拖動時，加上 `data-no-drag`。
- **右鍵**：顯示 WinWidget 的組件選單。某個區域要自己處理右鍵時，加上 `data-no-menu`。
- **縮放**：`size.resizable` 不是 `false` 時，右下角會有縮放手把。

## 權限

組件預設只能顯示自己的內容：不能連網、讀不到系統資訊、也碰不到你電腦上的檔案。要用到這些，在 `widget.json` 的 `permissions` 裏聲明：

| 權限 | 允許 |
|---|---|
| `system` | `widget.system`：處理器、記憶體、網速、磁碟、電池 |
| `network:api.example.com` | 連到這個網站 |
| `network:*.example.com` | 連到 example.com 和它所有的子網域 |
| `network:*` | 連到任何網站（用戶安裝時會看到明顯的提示，能不用就不用） |
| `shell.open` | `widget.shell.open`：用瀏覽器打開網址 |
| `notify` | `widget.notify`：顯示 Windows 通知 |
| `audio` | `widget.audio`：讀取和調整系統音量、靜音 |
| `media` | `widget.media`：讀取正在播放的歌名、封面，播放、暫停、切換曲目 |
| `clipboard` | `widget.clipboard`：讀取和寫入剪貼簿裏的文字（用戶允許時會看到明顯的提示） |
| `screen` | `widget.screen.capture`：把整個螢幕截成圖片（用戶允許時會看到明顯的提示） |
| `shell.launch` | `widget.shell.launch`、`pick`、`save`、`reveal`、`trash`、`info`、`paths`、`fileIcon`：打開程式和檔案、選檔案、選儲存位置、在檔案總管裏顯示、丟進資源回收筒、讀取名稱和圖標（用戶允許時會看到明顯的提示） |

讀取資料夾不用聲明權限：用戶在設定裏選了哪個資料夾，組件就只能讀那個資料夾裏的圖片，見 [`widget.files`](#讀取用戶選的資料夾widgetfiles)。

**誰來允許：**

- 用「新建組件」建立的組件是你自己寫的，聲明的權限直接生效。
- 別人的組件，安裝時會列出它要的權限，用戶按「安裝」才算允許。更新後多要了權限，用戶要再允許一次，在那之前新權限用不了。
- 把別人的組件資料夾直接放進組件目錄的話，第一次放上桌面時會先請用戶允許。

**連網的規則：** 不只 `widget.fetch`，頁面裏直接載入的圖片、字體、腳本、`fetch()` 和 WebSocket 也只能連到允許的網站。差別是：直接 `fetch()` 要對方網站支援 CORS，`widget.fetch` 不用。

## 除錯

在控制中心「設定」打開 **開發者模式**（用「新建組件」時會自動打開）。打開後：

- **存檔即重新載入**：組件資料夾裏任何檔案存檔後，用到它的組件會自動重新載入；改了 `widget.json`，新的尺寸和設定項也會立即生效。
- **錯誤提示**：腳本出錯時，卡片底部會顯示錯誤和位置，點一下打開開發者工具。
- **開發者工具**：在組件上按 F12，或控制中心「我的組件 → 位置與行為 → 開發者工具」。F5 重新載入。
- **日誌**：`widget.log()` 的內容和組件的錯誤，都寫在 `%LocalAppData%\WinWidget\logs\app.log`。
- **沒有載入的組件**：`widget.json` 寫錯（例如少了逗號、id 不合規則、找不到入口檔），「添加組件」頁頂部會列出是哪個資料夾、哪一行、什麼問題。

**命令列**（在終端機執行，作用在正在運行的 WinWidget 上）：

```bat
WinWidget.exe --cmd="reload me.daily-quote"
WinWidget.exe --cmd="devtools me.daily-quote"
WinWidget.exe --cmd="add me.daily-quote"
WinWidget.exe --cmd="rescan"
WinWidget.exe --cmd="export me.daily-quote D:\out\daily-quote.fwz"
WinWidget.exe D:\downloads\daily-quote.fwz
```

`reload`、`devtools` 也可以用桌面上某一個的識別碼（控制中心「位置與行為」裏的「識別碼」）。

## 打包和分享

`.fwz` 就是把組件資料夾壓成 zip、改了副檔名。

- **匯出**：控制中心「添加組件」→ 你的組件卡片 →「匯出 .fwz」。隱藏的檔案和資料夾（例如 `.git`）以及 `node_modules` 不會被打包。
- **安裝**：雙擊 `.fwz` 檔案、把它拖到控制中心視窗上，或在「添加組件」按「安裝 .fwz 檔案…」。安裝前會顯示名稱、作者、版本和需要的權限。
- **更新**：改大 `version` 再匯出。`id` 相同的組件會被替換，桌面上的組件、設定和保存的資料都會保留；舊版本移到資源回收筒。
- **用框架寫**：React、Vue、Svelte 都可以，只要輸出靜態檔案。把建置結果（例如 `dist/`）和 `widget.json` 放在一起，`entry` 指向它的 `index.html`；資源路徑要用相對路徑（例如 Vite 設 `base: "./"`）。
- **大小限制**：`.fwz` 最大 64 MB，解壓後最多 256 MB、5000 個檔案。

## 和 uTools 插件的關係（相容到哪一步）

uTools 的插件是 Electron 應用：`plugin.json` + `preload.js`（在 Node 環境裏 `require("fs")`、裝 Sharp / FFmpeg）+ 頁面。WinWidget 是 Rust + WebView2，**沒有 Electron，也沒有 Node**，所以 uTools 插件不可能原樣搬進來。能搬的是「頁面 + 頁面上呼叫 `utools.*` 的那部分能力」：每個組件頁都會被注入一份 `utools` 相容層（`/__fw/utools.js`），把它接到 WinWidget 自己的宿主能力上。

### 想把一個現成 uTools 插件的畫面搬進來

1. 把插件的 `index.html`、CSS、JS 放進一個組件資料夾；
2. 在 `widget.json` 裏按它用到的能力聲明 `permissions`（`showNotification` → `notify`、`copyText` → `clipboard`、`captureScreen` → `screen`、`shellOpenPath` → `shell.launch`、`shellOpenExternal` → `shell.open`）；
3. 頁面上呼叫的 `utools.*` 由相容層處理，不必改程式碼。

**不要指望**：`preload.js`、`require(...)`、`process`、`ipcRenderer`、`fs`、`child_process`。這些在 WinWidget 裏不存在，把 preload 原封不動搬進來只會得到一片空白。

### 先問一句：這個 API 有沒有

```js
if (utools.__compat.supports("captureScreen")) {
  const png = await utools.captureScreen();        // PNG data URL
} else {
  document.body.textContent = "這個宿主沒有螢幕截圖";
}
console.log(utools.__compat.degraded);    // 有，但語意變了
console.log(utools.__compat.unsupported); // 完全沒有
```

### 依 uTools 文件的分類逐項對照

| uTools 的分類 | WinWidget 裏的情況 |
|---|---|
| 事件 | `onPluginReady`、`onPluginEnter`、`onPluginOut(isKill)` 都有，順序和 uTools 一致（ready 跑完才 enter，隱藏是 `false`、移除/結束是 `true`）；`onPluginDetach` 會登記但不觸發，`onScheduleTrigger` / `onMainPush` / `onDbPull` 註冊時拋 `utools.unsupported`。宿主自己的生命週期事件見「生命週期」那一章 |
| 窗口 | `hideMainWindow`、`showMainWindow`、`outPlugin`、`getWindowType`、`setExpendHeight`（只改高度，而且是異步） |
| 系統 | `showNotification`、`shellOpenPath`、`shellOpenExternal`、`shellShowItemInFolder`、`shellTrashItem`、`shellBeep`、`getPath`、`getFileIconAsync`、`showOpenDialog`、`showSaveDialog`、`isDev`、`isWindows`…；`getPluginLocalDataPath` 回空字串（沒有檔案系統） |
| 螢幕 | `captureScreen()` 截整塊虛擬桌面，回傳 PNG data URL（需要 `screen` 權限）；uTools 那種「拖一個框」的互動截圖沒有 |
| 輸入 | 沒有。uTools 的 `simulate` 類 API（鍵盤、滑鼠注入）不在相容層裏 |
| 複製 | `copyText` 有（`clipboard` 權限）；`copyImage`、`getCopyedFiles` 沒有——剪貼簿只處理文字 |
| 資料庫 | `dbStorage` 的 `getItem` / `setItem` / `removeItem` / `clear`，同步、存在本組件的 local storage 裏；**沒有雲端同步**，uTools 那種帶 `_id` 的文件庫 `db` 也沒有 |
| AI 能力 | 沒有。沒有 uTools 帳號和雲端模型，也沒有 Node 去接本地模型 |
| 定時任務 | 沒有 uTools 的排程器；要定時就用 `widget.notify({ at })` 或頁面自己的 `setTimeout` |
| 模擬操作 | 沒有 |
| 動態功能 | 沒有 |
| 快捷入口 | 沒有。WinWidget 自己是桌面組件，入口是托盤和控制中心 |
| uBrowser 瀏覽器 | 沒有內嵌瀏覽器視窗；要開網頁用 `utools.shellOpenExternal` 或 `widget.shell.open` |
| Sharp 圖片處理 | 沒有。原生模組搬不進來；圖片處理用 Canvas，或把結果交給宿主 |
| FFmpeg 音視頻處理 | 沒有 |
| 支付 | 沒有 |

沒有實作的 API 不會安安靜靜回 `undefined`：呼叫時拋一個 `code: "utools.unsupported"` 的錯誤，訊息寫明是哪一項、為什麼。這樣比 `TypeError: utools.xxx is not a function` 好查。

### 新寫組件不必繞 uTools

相容層是給「已經存在的網頁」用的。新組件直接用 `widget.*`：型別完整（`widget.d.ts`）、有權限模型、跟主題走、錯誤訊息清楚。同一件事兩邊都有時，`widget.*` 是主路徑，`utools.*` 是相容路徑。

## 和外殼怎麼對接（進階）

前面幾章的寫法已經能做出完整的組件。這一章寫給想知道「它到底怎麼跑起來」的人：頁面從哪來、外殼塞了什麼進來、有哪些訊息、資料放在哪。看清楚這些，除錯和做進階功能都會快很多。

### 頁面是怎麼被載入的

WinWidget 不是用 `file://` 打開你的 `index.html`，而是啟動一個只綁定 `127.0.0.1` 的小型 HTTP 服務，頁面由它提供：

```
http://127.0.0.1:<連接埠>/__fw/<組件 id>/index.html
```

- **連接埠每次啟動都可能不同**，所以永遠寫相對路徑（`style.css`、`main.js`、`img/a.png`），不要寫死 `127.0.0.1:8800`。
- 每一種組件有自己的 origin：`<組件id>.widgets.localhost`。`localStorage`、`IndexedDB`、`Cache` 都按 origin 隔離，同一種組件的多個實例共用這一份。
- 頁面不能自行跳轉到別的網址，也不能開新視窗；要開網頁請用 `widget.shell.open`。
- 頁面裏載入的圖片、字體、腳本，同樣受 `permissions` 的 `network:` 限制。

### 啟動時外殼塞進來的東西

在你的任何腳本執行之前，外殼會把這些放在 `window.__FW_BOOT__`：

| 欄位 | 內容 |
|---|---|
| `settings` | 這個實例的全部設定值（已按語言折疊，見下） |
| `appearance` | 目前外觀：`theme`、`style`、`shadow`、`themeCss`、`themeHref`、`userCss` 等 |
| `locked` | 是否被用戶鎖定 |
| `layer` | 目前的層級：`desktop` / `normal` / `top` |
| `clickThrough` | 是否開着滑鼠穿透 |
| `state` | `{ edit, label }`：排列模式、卡片上那個名稱標籤 |
| `developer` | 是否在開發者模式 |
| `locale` | 用戶語言，例如 `zh-TW` |
| `permissions` | 現在真的能用的權限（已聲明且用戶已允許的） |
| `hostVersion` | WinWidget 版本，例如 `1.0.0` |
| `widgetId` / `instanceId` | 組件 id、桌面上這一個的識別碼 |
| `size` | `{ width, height, grow }`，`width`/`height` 是預設尺寸 |
| `resizable` | 是否允許縮放 |

`widget-sdk.js` 讀完這一份才建立 `window.widget`，所以你在 `main.js` 第一行就能用 `widget`。

### 訊息協議

`widget.*` 的每一個方法，最後都是一則訊息。想不通某個行為時，直接在開發者工具裏看訊息最有效：

```js
// 呼叫：{ id, m, p }；外殼回：{ id, r } 或 { id, e: "錯誤訊息" }
chrome.webview.postMessage(JSON.stringify({ id: 7, m: "storage.get", p: { key: "todo" } }));

// 不需要回應的（拖動、開選單）：{ m, p }
chrome.webview.postMessage(JSON.stringify({ m: "window.menu" }));

// 外殼主動推：{ ev: "settings" | "appearance" | "state" | "system" | "audio" | "media" | "identify", d: … }
chrome.webview.addEventListener("message", (e) => console.log(e.data));
```

日常用 SDK 就好，這一層是給你排查問題的：SDK 的錯誤訊息會前後帶上目標，例如 `HTTP 404 (https://api.example.com/x)`。

## 三個完整例子

### 例 1：把一個網路 API 的數字放上桌面

需求：顯示某個 GitHub 專案的 star 數，每 30 分鐘更新，斷網時顯示上次的值。

`widget.json` 重點：`"permissions": ["network:api.github.com"]`。

```js
const $ = (id) => document.getElementById(id);
const KEY = "last";

async function fetchOnce() {
  const r = await widget.fetch("https://api.github.com/repos/Demon1110/WinWidget", {
    headers: { accept: "application/vnd.github+json" },
  });
  if (!r.ok) throw new Error(`HTTP ${r.status}`);
  const repo = await r.json();
  return { stars: repo.stargazers_count, at: Date.now() };
}

async function refresh() {
  try {
    const data = await fetchOnce();
    show(data, false);
    await widget.storage.set(KEY, data);
  } catch (e) {
    // 失敗時退回上次的值，並在角落標一下「舊資料」
    const old = await widget.storage.get(KEY);
    if (old) show(old, true);
    else $("stars").textContent = "—";
    widget.log(`stars: ${e.message}`);
  }
}

function show(data, stale) {
  $("stars").textContent = data.stars.toLocaleString(widget.locale);
  $("at").textContent = new Date(data.at).toLocaleTimeString(widget.locale, { hour: "2-digit", minute: "2-digit" });
  $("stale").hidden = !stale;
}

refresh();
setInterval(refresh, 30 * 60 * 1000);   // 30 分鐘
document.addEventListener("visibilitychange", () => { if (!document.hidden) refresh(); });
```

要點：

- `permissions` 要寫 `network:api.github.com`（不是 `*.github.com`：能少就少）。
- 先寫畫面再寫資料，或像上面一樣「失敗也有東西可顯示」，卡片不會一片空白。
- 定時器用 `setInterval` 就好；不要每秒輪詢，`widget.media`、`widget.audio` 這類有事件的就用 `onChange`。

### 例 2：每秒更新的系統監控（省電寫法）

```js
const $ = (id) => document.getElementById(id);
const bars = [];

// 一次訂閱兩個主題；WinWidget 會合成一筆資料給你
widget.system.subscribe(["cpu", "memory"], (d) => {
  if (d.cpu) {
    $("cpu").textContent = `${Math.round(d.cpu.usage)}%`;
    push(bars[0], d.cpu.usage);
  }
  if (d.memory) {
    $("mem").textContent = `${Math.round(d.memory.usage)}%`;
    push(bars[1], d.memory.usage);
  }
}, { interval: 1000 });

/** 20 格的迷你曲線；每秒更新，所以不加 transition。 */
function push(bar, value) {
  const cell = document.createElement("i");
  cell.style.height = `${Math.max(4, Math.min(100, value))}%`;
  bar.appendChild(cell);
  if (bar.children.length > 20) bar.firstElementChild.remove();
}
```

```css
#cpu, #mem { font-variant-numeric: tabular-nums; }   /* 數字不會左右跳 */
.mini { display: flex; align-items: flex-end; gap: 1px; height: 1.6rem; }
.mini i { width: 2px; background: var(--w-accent); } /* 不要 transition / animation */
```

要點：

- 每秒更新的元素不要 `transition`、不要 `animation`：一個 0.5 秒的動畫等於整張卡片一直在重畫，處理器會一直有負擔。
- 數字用 `font-variant-numeric: tabular-nums`，寬度不會隨數字變動而抖。
- 訂閱用完要退訂（`const stop = widget.system.subscribe(...); stop()`），否則卡片一直有取樣成本。

### 例 3：同一個組件放兩個，各記各的

```js
// 卡片自己在拖動和縮放時會變，實例識別碼不會變：用它當資料分界
const key = `state:${widget.instanceId}`;

const saved = await widget.storage.get(key);
index = saved ? saved.index : 0;

function save() {
  widget.storage.set(key, { index });   // 不用 await，寫入很快
}
```

要點：`widget.storage` 的鍵是**組件**級別的（同一組件的兩個實例共用一個檔案），要分開保存就在鍵裏帶上 `instanceId`；設定值（`settings`）則是每個實例各自一份。

## 寫組件的檢查清單

交付前逐條看一眼，能省掉九成的「裝上去怪怪的」：

1. `widget.json` 的 `id` 只用小寫英文、數字和 `. _ -`，2–64 字元，之後不再改。
2. `entry` 指向的檔案真的存在；所有資源都用**相對路徑**。
3. 檔案存成 UTF-8（沒有 BOM 也可以，有 BOM 會讓 JSON 解析失敗）。
4. 用到的能力都在 `permissions` 裏聲明；能用 `network:某個網站` 就不要 `network:*`。
5. 第一次載入就有東西看：先畫版面，再等資料；取不到時給一句人話，不要空白。
6. 每秒更新的元素不加動畫；不定時輪詢已經有事件的功能。
7. 數字和日期用 `widget.locale` 格式化，文字用 `widget.t()`。
8. 只用 `--w-*` 變數和 `w-*` 樣式，三套主題切一遍都不會看不到字。
9. 卡片可以被拉大縮小：用 flex/grid，必要時 `@container`；想讓內容跟着放大就設 `grow`。
10. 不要寫 `window.open`、頁面跳轉、`document.write`；要開網頁用 `widget.shell.open`。
11. 不要引用 CDN 上的腳本或字體（離線就壞了），要打包進組件資料夾。
12. 送出前在開發者模式按 F12 看一遍 Console，沒有紅色錯誤再匯出 `.fwz`。

## 常見問題

**改了檔案，桌面上沒變化。**
確認「設定」裏開發者模式是開的。沒開的話，在組件上右鍵 →「重新載入」。如果改的是 `widget.json` 而組件不見了，看「添加組件」頁頂部是不是列出了錯誤。

**`widget.fetch` 失敗，說 permission denied。**
把那個網站加進 `permissions`，例如 `"network:api.example.com"`。錯誤訊息裏會寫出要加的那一行。如果說 "not allowed yet"，表示已經聲明但用戶還沒允許：到控制中心「我的組件」選這個組件，按「查看並允許」。

**直接用 `fetch()` 或 `<img>` 載入網路上的東西失敗。**
網站要在 `permissions` 裏。`fetch()` 還要對方支援 CORS；不支援的話改用 `widget.fetch`。

**中文變成亂碼。**
把檔案存成 UTF-8。

**想讓組件第一次出現時大一點或小一點。**
改 `size.width` 和 `size.height`。已經在桌面上的組件會保留用戶調過的大小，可以從「添加組件」再放一個新的來看效果。

**怎樣讓組件在淺色主題（紙本）下也好看？**
文字和線條都用 `--w-*` 變數，不要寫死白色或黑色。到控制中心「主題」切換三套主題看一遍。

**改了「語言」設定，組件還是原本的語言。**
語言在**啟動時**讀 `config.json`，改了要重新啟動 WinWidget（控制中心「設定」裏的語言會立即影響控制中心本身，桌面上已經開着的組件要重新載入才會換）。組件裏請一律用 `widget.locale` / `widget.t()`，不要自己判斷系統語言。

**控制中心按「組件目錄」「資料位置」沒反應，提示「沒有成功」。**
這兩個按鈕由 WinWidget 用系統的方式打開資料夾（等同在檔案總管裏雙擊）。如果完全沒反應：先確認路徑存在（按鈕會自動建立目錄），再看 `%LocalAppData%\WinWidget\logs\app.log` 裏那一行錯誤。舊版本把資料夾當成網址開啟，所以一定會失敗，更新到最新版即可。

**「檢查更新」說沒有更新通道 / 檢查不到。**
`config.json` 的 `update_url` 留空時，預設讀本專案 GitHub Releases 的最新版本（`api.github.com`）。要換成自己的通道，就在 `update_url` 填一個 JSON 位址，內容是 `{"version": "1.2.0", "url": "下載位址", "size": 文件大小, "notes": "更新說明", "page": "介紹頁"}`。檢查和下載都在背景執行，不會讓介面卡住；開發者模式不允許自我更新。

**媒體組件裏「顯示是哪個程式在播放」關掉還有字。**
那是組件頁面自己的顯示邏輯，最新版已修好。若還留着，確認組件資料夾裏的 `style.css` 是最新的（`body.no-app .app { display: none }`）。
